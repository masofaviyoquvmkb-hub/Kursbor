# KURSBOR — главная страница

Стриминговая платформа для творческих работ. React + Vite + Tailwind CSS v4 + Framer Motion.
Весь интерфейс на русском языке.

## Запуск

Нужен Node.js 20+ (проверено на Node 22).

```bash
npm install
npm run dev        # http://localhost:5173
```

Сборка для хостинга:

```bash
npm run build      # готовый сайт в папке dist/
npm run preview    # посмотреть собранную версию локально
```

Папку `dist/` можно загрузить на любой статический хостинг (Netlify, Vercel, Cloudflare Pages, nginx).
Для kursbor.uz сайт работает из корня домена — ничего менять не нужно.

### Видео на главном экране

Ваш ролик (Full HD, со звуком) стоит фоном первого экрана.

- Запускается сам **без звука** и идёт по кругу: браузеры не разрешают сайтам включать звук без действия посетителя.
- Кнопка **«ВКЛЮЧИТЬ ЗВУК»** внизу включает звук и продолжает с того же места.
  Заголовок и кнопки в это время плавно уходят, чтобы видео было видно целиком.
- Когда ролик досмотрен со звуком, он сам возвращается в тихий режим, и текст появляется снова.
- При прокрутке вниз или переключении вкладки видео встаёт на паузу.
- Красная полоса внизу — настоящий таймлайн ролика, по ней можно перематывать.

Оригинал 20 МБ сжат до 1,3 МБ (WebM, Chrome/Android) и 2,4 МБ (MP4, Safari/iPhone) без видимой потери качества.
Каждый посетитель загружает только один из файлов.

Как заменить ролик новым видео:

```bash
ffmpeg -i original.mp4 -c:v libx264 -preset veryfast -crf 23 -pix_fmt yuv420p -movflags +faststart -c:a aac -b:a 128k public/hero/hero.mp4
ffmpeg -i original.mp4 -c:v libvpx-vp9 -b:v 0 -crf 36 -row-mt 1 -pix_fmt yuv420p -c:a libopus -b:a 112k public/hero/hero.webm
ffmpeg -i original.mp4 -frames:v 1 -q:v 3 public/hero/hero.jpg
```

Чтобы вместо видео была просто картинка, поставьте `webm: ''` и `mp4: ''` в `src/data/site.js`.

### Электронные курсы

Курсы живут в iSpring Cloud, а KURSBOR только показывает их: обложка, название, описание и кнопка «СМОТРЕТЬ КУРС».
По кнопке курс открывается в полноэкранном окне поверх сайта (iframe с iSpring), без перехода на другой сайт.
Закрыть — крестик × или Esc; посетитель возвращается на то же место страницы.

Добавление курса — один новый блок в `src/data/courses.js`. Пошагово: **`КАК_ДОБАВИТЬ_КУРС.md`**.

Окно просмотра (`EmbedViewerModal.jsx`) универсальное: сейчас умеет `iframe` (iSpring и любые embed-плееры)
и `video` (mp4/webm). Позже его же можно использовать для видео, Reels, презентаций и Love story.

### Раздел «Обо мне»

Профиль автора в стиле стриминговой платформы. Порядок блоков: портрет и имя → цифры → «Что я делаю» →
AI-студия → «Инструменты» → «С кем я работал» → цитата с фрагментом шоурила → финальный кадр с кнопкой «Заказать проект».

Все тексты в `src/data/about.js`. Компоненты лежат в `src/components/about/`, менять их не нужно.

**Фото:** положите свою фотографию вместо `public/images/about/ravshan.jpg` (сейчас там заглушка с монограммой).
Лучше вертикальное фото 4:5, например 1200×1500. Если файла не будет, покажется аккуратная заглушка с инициалами.

### Форма «Заказать проект»

Все кнопки «ЗАКАЗАТЬ ПРОЕКТ» (в меню, на первом экране и в конце «Обо мне») ведут к форме внизу страницы:
имя, контакт, что нужно создать, коротко о проекте.

- **Сейчас** (поле `order.endpoint` пустое): при отправке текст заявки копируется, и открывается ваш Telegram
  (`contacts.telegram`). Посетителю остаётся вставить текст в чат и нажать «Отправить».
  Telegram не позволяет сайтам заранее вписать сообщение в личный чат, поэтому текст копируется.
- **Позже** можно подключить приём заявок без почты: укажите в `order.endpoint` адрес своего сервера,
  Telegram-бота или сервиса форм (например, Formspree). Заявка уйдёт туда POST-запросом в JSON:
  `{ name, contact, types, message, source }`.

### Контакты внизу сайта

Блок «Давайте начнём следующий проект.»: кнопка «НАЧАТЬ ПРОЕКТ →» ведёт сразу в Telegram,
ниже Telegram (главный способ связи), Instagram, два телефона (нажатие запускает звонок) и адрес.
Всё берётся из блока `contacts` в `src/data/site.js`:

- `telegram.href` — ссылка на Telegram (на неё же ведут «НАЧАТЬ ПРОЕКТ» и форма заказа);
- `instagram.href` — ссылка на Instagram;
- `phones` — `label` как номер выглядит на сайте, `href` — `tel:` и цифры без пробелов;
- `address` — строки адреса.

### Раздел «Записаться на курс»

Пункт меню «ЗАПИСАТЬСЯ НА КУРС» плавно прокручивает к разделу внизу страницы:
«ЗА МЕСЯЦ СДЕЛАЮ ИЗ ВАС РАЗРАБОТЧИКА ЭЛЕКТРОННЫХ КУРСОВ», факты о курсе, кнопки «ОБСУДИТЬ ОБУЧЕНИЕ»
(ведут в Telegram из `contacts.telegram`) и картинка с программой курса. По нажатию программа открывается
на весь экран в полном разрешении (на телефоне её можно листать и увеличивать пальцами).

Меню целиком помещается в строку на экранах от 1280px; на более узких открывается кнопкой-«бургером».

│   ├── Footer.jsx        контакты: Telegram, Instagram, телефоны, адрес + «НАЧАТЬ ПРОЕКТ»
│   ├── SectionTitle.jsx
│   └── Icons.jsx
├── data/
│   ├── courses.js        ВАШИ КУРСЫ — добавляйте сюда
│   ├── about.js          тексты раздела «Обо мне»
│   ├── site.js           все тексты и настройки
│   ├── projects.js       прочие работы (заглушки)
│   └── works.js          собирает курсы + работы вместе (не трогать)

Пункт меню «Курсы» ведёт в раздел «Электронные курсы». «Видео» и «Презентации» пока прокручивают к «Избранным работам» с нужным фильтром,
«Обо мне» — в раздел «Обо мне». Когда появятся отдельные страницы, замените `href` в `navLinks` (`src/data/site.js`).

Анимации учитывают системную настройку «уменьшить движение».
