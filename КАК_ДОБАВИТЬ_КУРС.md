# Как добавить новый курс на KURSBOR

Все курсы хранятся в **одном файле**: `src/data/courses.js`.
Компоненты трогать не нужно. Новый курс автоматически появится:

- в разделе **«Электронные курсы»**;
- в **«Избранных работах»** (фильтр «Курсы»);
- в **поиске** 🔍.

## Шаг 1. Возьмите ссылку из iSpring Cloud

В iSpring Cloud откройте курс → «Поделиться» / «Встроить» → скопируйте код. Он выглядит так:

```html
<iframe src="https://acc-12404.ispring.ru/app/embed-player/2d21d138-…" width="560" height="315" …></iframe>
```

Нужна только ссылка внутри `src="…"`:

```
https://acc-12404.ispring.ru/app/embed-player/2d21d138-…
```

## Шаг 2. Положите обложку

Скопируйте картинку в папку `public/images/courses/`, например `public/images/courses/finance.jpg`.
Лучший размер — 1600×900 (формат 16:9). Если картинки пока нет, ничего страшного:
карточка покажет красивую заглушку с названием курса.

## Шаг 3. Добавьте курс в `src/data/courses.js`

Скопируйте блок первого курса и вставьте его **после** него, через запятую:

```js
const courses = [
  {
    id: 1,
    title: 'Онлайн микрозайм',
    …
  },
  {
    id: 2,
    title: 'Финансовая грамотность',
    subtitle: 'Интерактивный тренажёр',
    description: 'Короткое описание курса.',
    category: 'E-Learning',
    image: '/images/courses/finance.jpg',
    embedUrl: 'https://acc-12404.ispring.ru/app/embed-player/ВАШ-КОД',
    year: 2026,
  },
]
```

Сохраните файл. Если запущен `npm run dev`, сайт обновится сам.

## Что где менять

| Что | Поле в `src/data/courses.js` |
|---|---|
| Название курса | `title` |
| Подпись под названием (необязательно) | `subtitle` |
| Описание | `description` |
| Категория на карточке | `category` |
| Картинка | `image` — путь вида `'/images/courses/имя.jpg'` |
| Ссылка на курс в iSpring | `embedUrl` |
| Длительность (необязательно) | `duration`, например `'20 минут'` |
| Год (необязательно) | `year` |

Строки `subtitle`, `duration` и `year` можно просто удалить, если они не нужны.

## Частые ошибки

- **Забыли запятую** между курсами `},  {` — сайт покажет ошибку. Проверьте запятые.
- **Кавычки**: текст пишется в одинарных кавычках `'…'`. Если в тексте есть апостроф, используйте двойные `"…"`.
- **Неверный путь к картинке**: путь начинается с `/images/courses/`, без слова `public`.
- **Вставили весь `<iframe …>`** в `embedUrl` — нужна только ссылка из `src`.
- `id` у каждого курса должен быть своим (1, 2, 3 …).

Если курс один, он показывается большой карточкой. Когда курсов два и больше, они выстраиваются сеткой.
